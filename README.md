# WorkAid

> 一站式文档批处理工具箱 —— 10 个常用文档处理功能，批量处理，拖拽即用。

Windows 桌面端文档处理工具，免安装便携版，解压双击即可运行。**文件全程本机处理，不联网。**

## 下载

前往 [Releases](../../releases/latest) 下载最新的 `WorkAid_vX.Y.Z_portable.zip`，解压到任意目录即可使用，不写注册表、不装系统服务。

> 本仓库只存放安装包，不包含源代码。

## 功能

| 功能 | 说明 |
| --- | --- |
| Word 转 PDF | 批量将 Word 文档转为 PDF |
| PDF 转 Word | 批量将 PDF 转为可编辑的 Word（无需本机安装 Office） |
| PPT 转 PDF | 批量将 PPT 演示文稿转为 PDF |
| PDF 转图片 | 将 PDF 每一页导出为图片 |
| PDF 加水印 | 批量为 PDF 添加文字或图片水印，支持平铺/居中、浓度与角度调节 |
| PDF 合并 | 将多个 PDF 合并为一个 |
| PDF 拆分 | 按每页拆分或按页码范围拆分 |
| 图片转 PDF | 将多张图片合并为一个 PDF |
| 图片重命名 | 批量重命名：模板编号 / 前后缀 / 查找替换，实时预览新文件名 |
| 图片格式转换 | PNG / JPG / WEBP / BMP / TIFF / ICO 批量互转 |
